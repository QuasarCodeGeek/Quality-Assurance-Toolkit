# Module 05 — Non-Functional Testing Types

## Overview

This module introduces the most common Non-Functional Testing types used to evaluate the quality attributes of a software application.

Unlike Functional Testing, which verifies what the software does, Non-Functional Testing evaluates **how well** the software performs. These tests measure characteristics such as performance, security, usability, accessibility, compatibility, and system stability under different conditions.

The guides in this module cover the non-functional testing techniques most frequently used in real-world software projects.

---

## Learning Objectives

After completing this module, you should be able to:

* Understand the purpose of Non-Functional Testing.
* Differentiate between performance-related testing techniques.
* Recognize the importance of security, usability, accessibility, and compatibility testing.
* Select appropriate non-functional tests based on software quality requirements.

---

## Guides

| Guide                     | Description                                                                                                      |
| ------------------------- | ---------------------------------------------------------------------------------------------------------------- |
| **Performance Testing**   | Evaluates the responsiveness, speed, and stability of an application under expected workloads.                   |
| **Load Testing**          | Verifies application behavior under expected user or transaction loads.                                          |
| **Stress Testing**        | Determines how the application behaves beyond its expected operating limits.                                     |
| **Security Testing**      | Identifies vulnerabilities and verifies that the application protects data and resources.                        |
| **Compatibility Testing** | Ensures the application works correctly across supported devices, browsers, operating systems, and environments. |
| **Accessibility Testing** | Verifies that the application is usable by people with disabilities and complies with accessibility guidelines.  |
| **Usability Testing**     | Evaluates how easy, intuitive, and efficient the application is for end users.                                   |
