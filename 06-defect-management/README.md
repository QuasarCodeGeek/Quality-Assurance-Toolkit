# Module 06 — Defect Management

## Overview

This module focuses on the processes and documentation used to identify, track, prioritize, and resolve software defects throughout the Software Testing Life Cycle (STLC).

Defect Management is an essential part of Quality Assurance. Discovering a defect is only the beginning—teams must also document it clearly, assign the appropriate severity and priority, monitor its progress, and verify that it has been resolved correctly.

The guides in this module introduce the fundamental concepts and workflows used to manage software defects effectively.

---

## Learning Objectives

After completing this module, you should be able to:

* Understand the defect management process from discovery to closure.
* Create clear and reproducible Bug Reports.
* Explain the Defect Life Cycle and common defect statuses.
* Differentiate between Severity and Priority.
* Track and communicate defects throughout the testing process.
