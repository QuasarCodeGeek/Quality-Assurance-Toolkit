# Module 08 — Requirements Management

## Overview

This module focuses on understanding, documenting, and managing software requirements throughout the Software Development Life Cycle (SDLC) and Software Testing Life Cycle (STLC).

Well-defined requirements are the foundation of successful software testing. Before Test Scenarios and Test Cases can be created, testers must understand what the system is expected to do, how success will be measured, and how requirements can be traced throughout development and testing.

The guides in this module introduce the essential documents and techniques used to ensure that software requirements are complete, testable, and fully covered during testing.

---

## Learning Objectives

After completing this module, you should be able to:

* Understand the different types of software requirements.
* Write and evaluate effective Acceptance Criteria.
* Differentiate between User Stories and Requirements.
* Use a Requirements Traceability Matrix (RTM) to ensure complete test coverage.
* Maintain traceability between requirements and testing artifacts.

## Summary

This module emphasizes the importance of well-defined and traceable software requirements in the testing process.

By understanding requirement types, defining clear acceptance criteria, comparing user stories with traditional requirements, and maintaining traceability through an RTM, teams can improve test coverage, reduce missed requirements, and deliver software that meets business expectations.
