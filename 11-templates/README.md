# Module 11 — Templates

## Overview

This module provides reusable templates for the most common documents used throughout the Software Testing Life Cycle (STLC).

Creating testing documents from scratch can be time-consuming and may lead to inconsistencies across projects. These templates provide standardized formats that teams can adapt to their own workflows, helping improve documentation quality, collaboration, and maintainability.

Whether you are planning a testing effort, documenting Test Cases, reporting defects, or preparing release documentation, these templates offer a practical starting point for real-world software projects.

---

## Learning Objectives

After completing this module, you should be able to:

* Use standardized templates for common QA documents.
* Create consistent testing documentation across projects.
* Customize templates to fit organizational standards and project requirements.
* Improve documentation quality and traceability throughout the testing lifecycle.
* Reduce the time required to prepare common QA artifacts.

## Guides

| Template                                            | Description                                                                      |

| **Test Plan Template**                              | Standardizes project-specific testing plans and execution details.               |
| **Test Scenario Template**                          | Provides a structure for documenting high-level testing scenarios.               |
| **Test Case Template**                              | Standardizes detailed Test Case documentation for execution.                     |
| **Bug Report Template**                             | Provides a reusable format for documenting software defects.                     |
| **Requirements Traceability Matrix (RTM) Template** | Maps requirements to Test Scenarios, Test Cases, and testing results.            |
