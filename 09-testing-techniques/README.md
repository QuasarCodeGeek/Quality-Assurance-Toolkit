# Module 09 — Test Design Techniques

## Overview

This module introduces the most common test design techniques used to create effective and efficient Test Cases.

Rather than testing every possible input or scenario, QA engineers use structured techniques to select representative test data that provides good test coverage while minimizing unnecessary test cases. These techniques help identify defects more efficiently and improve the overall quality of software testing.

The guides in this module cover practical test design techniques that are widely used in manual testing and form the foundation of many automated testing strategies.

---

## Learning Objectives

After completing this module, you should be able to:

* Understand the purpose of test design techniques.
* Apply Boundary Value Analysis and Equivalence Partitioning to reduce the number of test cases.
* Use Decision Table Testing for complex business rules.
* Apply State Transition Testing to systems with changing states.
* Use Error Guessing to identify defects based on experience and intuition.

---

## Guides

| Guide                             | Description                                                                                       |
| --------------------------------- | ------------------------------------------------------------------------------------------------- |
| **Boundary Value Analysis (BVA)** | Tests values at the boundaries of valid and invalid input ranges.                                 |
| **Equivalence Partitioning (EP)** | Divides input data into equivalent groups to reduce redundant test cases.                         |
| **Decision Table Testing**        | Uses decision tables to verify combinations of business rules and conditions.                     |
| **State Transition Testing**      | Verifies application behavior as it moves between different states.                               |
| **Error Guessing**                | Uses tester experience and intuition to identify defects that structured techniques may overlook. |

## Summary

This module provides practical techniques for designing high-quality Test Cases while reducing unnecessary testing effort.

By applying structured test design methods, QA engineers can improve test coverage, identify defects more effectively, and create efficient test suites that focus on the areas most likely to reveal software issues.
