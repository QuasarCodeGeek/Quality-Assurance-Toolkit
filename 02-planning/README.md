# Module 02 — Test Planning & Design

## Overview

This module focuses on the planning and preparation activities that take place before software testing begins.

Effective testing starts with proper planning. Before executing tests, QA teams define the testing approach, identify what needs to be tested, prepare the required test data, and create the documents that guide the testing process.

The guides in this module introduce the essential planning artifacts used throughout the Software Testing Life Cycle (STLC) and provide a structured approach to designing effective tests.

---

## Learning Objectives

After completing this module, you should be able to:

* Understand the purpose of a Test Strategy and Test Plan.
* Create meaningful Test Scenarios and detailed Test Cases.
* Prepare appropriate Test Data for different testing situations.
* Execute Test Cases and accurately document results.
* Understand how planning documents support efficient software testing.

---

## Guides

| Guide              | Description                                                                |
| ------------------ | -------------------------------------------------------------------------- |
| **Test Strategy**  | Defines the overall testing approach, objectives, and scope for a project. |
| **Test Plan**      | Describes how testing activities will be organized and executed.           |
| **Test Scenarios** | Identifies high-level user workflows and features that should be tested.   |
| **Test Cases**     | Documents detailed test steps, expected results, and execution conditions. |
| **Test Data**      | Explains how test data is prepared and managed during testing.             |
| **Test Execution** | Describes how Test Cases are executed, recorded, and evaluated.            |

This module introduces the core planning and design activities that form the foundation of successful software testing.

By learning how to organize testing efforts, prepare documentation, create reusable Test Cases, and execute tests systematically, readers will be better equipped to deliver consistent, repeatable, and high-quality testing throughout the software development lifecycle.
