# Module 03 — Testing Fundamentals

## Overview

This module introduces the major categories of software testing and provides an overview of the testing approaches commonly used throughout the Software Testing Life Cycle (STLC).

Before learning specific testing methodologies such as Smoke Testing or Performance Testing, it is important to understand how software testing is broadly classified into Functional Testing, Non-Functional Testing, and the most common Software Testing Types.

These guides establish the foundation for the more specialized testing techniques covered in the following modules.

---

## Learning Objectives

After completing this module, you should be able to:

* Understand the difference between Functional and Non-Functional Testing.
* Identify the purpose of common software testing types.
* Recognize when different categories of testing should be applied.
* Build a solid foundation before exploring individual testing methodologies.

---

## Guides

| Guide                      | Description                                                                             |
| -------------------------- | --------------------------------------------------------------------------------------- |
| **Functional Testing**     | Verifies that software functions according to its specified requirements.               |
| **Non-Functional Testing** | Evaluates quality attributes such as performance, security, usability, and reliability. |
| **Software Testing Types** | Introduces the most common software testing types used in real-world projects.          |

## Summary

This module provides an overview of the primary categories of software testing that form the basis of modern QA practices.

Understanding these testing categories helps readers determine which types of testing are appropriate for different situations and prepares them for the more detailed testing methodologies covered in the next modules.
