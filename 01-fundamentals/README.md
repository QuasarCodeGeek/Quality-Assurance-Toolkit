# Module 01 — QA Fundamentals

## Overview

Welcome to the first module of the **Quality Assurance Toolkit**.

This module introduces the core concepts of Software Quality Assurance (QA) and Software Testing. Before creating Test Plans, writing Test Cases, or reporting defects, it is important to understand the fundamental principles that guide the software testing process.

The guides in this module provide the foundation for the rest of the handbook and establish a common understanding of quality assurance terminology, testing principles, and software testing workflows.

---

## Learning Objectives

After completing this module, you should be able to:

* Understand the difference between Quality Assurance (QA) and Quality Control (QC).
* Explain the fundamental principles of software testing.
* Describe the Software Testing Life Cycle (STLC).
* Understand the Defect Life Cycle.
* Distinguish between Severity and Priority when reporting defects.
