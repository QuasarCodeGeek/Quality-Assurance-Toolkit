# Module 10 — Testing Checklists

## Overview

This module provides practical testing checklists that can be used during software testing and release activities.

Unlike Test Cases, which verify specific requirements, testing checklists serve as reusable references to help QA engineers and developers ensure that common testing areas are not overlooked. They promote consistency, improve testing efficiency, and reduce the risk of missing critical verification steps.

The guides in this module contain ready-to-use checklists for common testing scenarios encountered in web, mobile, and API development.

---

## Learning Objectives

After completing this module, you should be able to:

* Understand the purpose of testing checklists.
* Use checklists to improve testing consistency.
* Perform structured verification before software releases.
* Adapt reusable checklists to different project requirements.
* Complement Test Cases with practical testing references.
