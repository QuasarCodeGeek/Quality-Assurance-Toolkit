# Module 07 — Test Metrics

## Overview

This module introduces the key metrics and reports used to measure the effectiveness, progress, and overall quality of software testing.

While executing Test Cases helps identify defects, Test Metrics provide objective data that allows QA teams and stakeholders to evaluate testing performance, monitor software quality, and make informed release decisions.

The guides in this module explain the most commonly used testing metrics and reporting documents found in real-world software projects.

---

## Learning Objectives

After completing this module, you should be able to:

* Understand the purpose of Test Metrics in software testing.
* Calculate and interpret common QA metrics.
* Measure test coverage and defect-related indicators.
* Analyze testing results to support release decisions.
* Summarize testing outcomes using a Test Summary Report.

---

## Guides

| Guide                   | Description                                                                           |
| ----------------------- | ------------------------------------------------------------------------------------- |
| **Test Metrics**        | Introduces the purpose and importance of software testing metrics.                    |
| **Test Coverage**       | Measures how much of the application's requirements or functionality has been tested. |
| **Defect Density**      | Measures the number of defects relative to the size of the software.                  |
| **Defect Leakage**      | Measures defects that escaped testing and were discovered after release.              |
| **Test Summary Report** | Summarizes testing activities, results, metrics, and release recommendations.         |
